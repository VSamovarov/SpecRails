# 📝 Заметки и черновики

> ⚠️ **Для AI агентов:** Содержимое этой папки НЕ является источником истины и НЕ должно использоваться как контекст без явного указания пользователя. Это рабочая область для временных заметок.

Эта папка для личных заметок, набросков и временных материалов во время разработки.

**Назначение:**
- Быстрые заметки и TODO
- Черновики идей и гипотез
- Временные эксперименты
- Рабочие материалы

**Не используйте как:**
- Источник архитектурных решений (см. `docs/`)
- Актуальную документацию (см. `docs/` и `README.md`)
- Контракты и спецификации (см. `contracts/`)
