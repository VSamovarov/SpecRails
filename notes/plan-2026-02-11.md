## 1️⃣ Стилгайд и автоформатирование

### Проблема
- В коде есть точки с запятой (не нравится)
- Нет единого стиля форматирования
- Нет автоматической проверки стиля

### Решение
Настроить **ESLint** + **Prettier** для TypeScript проекта

### Шаги выполнения

#### 1.1. Установка зависимостей

```bash
cd process-core-proto
npm install --save-dev \
  eslint \
  @typescript-eslint/parser \
  @typescript-eslint/eslint-plugin \
  prettier \
  eslint-config-prettier \
  eslint-plugin-prettier
```

**Что устанавливаем:**
- `eslint` — линтер для JavaScript/TypeScript
- `@typescript-eslint/parser` — парсер TypeScript для ESLint
- `@typescript-eslint/eslint-plugin` — правила TypeScript
- `prettier` — автоформатирование
- `eslint-config-prettier` — отключает конфликтующие правила ESLint
- `eslint-plugin-prettier` — запускает Prettier как правило ESLint

---

#### 1.2. Создание `.eslintrc.json`

```json
{
  "root": true,
  "parser": "@typescript-eslint/parser",
  "parserOptions": {
    "ecmaVersion": 2022,
    "sourceType": "module",
    "project": "./tsconfig.json"
  },
  "plugins": ["@typescript-eslint", "prettier"],
  "extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended",
    "plugin:prettier/recommended"
  ],
  "rules": {
    "prettier/prettier": "error",
    "@typescript-eslint/no-explicit-any": "warn",
    "@typescript-eslint/no-unused-vars": ["error", { "argsIgnorePattern": "^_" }],
    "no-console": "off"
  },
  "ignorePatterns": ["dist/", "node_modules/"]
}
```

---

#### 1.3. Создание `.prettierrc.json`

```json
{
  "semi": false,
  "singleQuote": false,
  "tabWidth": 2,
  "printWidth": 120,
  "trailingComma": "es5",
  "arrowParens": "avoid"
}
```

**Ключевые настройки:**
- `"semi": false` ← убираем точки с запятой! 🎉
- `"singleQuote": false` — двойные кавычки
- `"printWidth": 120` — 120 символов в строке
- `"trailingComma": "es5"` — trailing comma где поддерживается

---

#### 1.4. Добавление скриптов в `package.json`

```json
{
  "scripts": {
    "build": "tsc -p tsconfig.json",
    "test:smoke": "node dist/src/cli.js process:extract \"School public? yes -> dept review; no -> auto checks; then decision.\"",
    "lint": "eslint . --ext .ts",
    "lint:fix": "eslint . --ext .ts --fix",
    "format": "prettier --write \"**/*.{ts,json,md}\"",
    "format:check": "prettier --check \"**/*.{ts,json,md}\""
  }
}
```

**Новые команды:**
- `npm run lint` — проверка кода
- `npm run lint:fix` — автоисправление
- `npm run format` — форматирование всех файлов
- `npm run format:check` — проверка форматирования (для CI/CD)

---

#### 1.5. Форматирование существующего кода


#### 3.2. Создание GeminiAiProvider

Создать файл: `packages/parser/src/providers/gemini.ts`

```typescript
import { GoogleGenerativeAI } from "@google/generative-ai"
import type { AiProvider } from "../types.js"

export class GeminiAiProvider implements AiProvider {
  readonly name = "gemini"
  private client: GoogleGenerativeAI

  constructor(apiKey: string) {
    this.client = new GoogleGenerativeAI(apiKey)
  }

  async runStructured<T>(input: {
    system: string
    prompt: string
    schema: object
  }): Promise<{ data: T; rawText: string; model: string }> {
    const model = this.client.getGenerativeModel({
      model: "gemini-1.5-flash",
      generationConfig: {
        responseMimeType: "application/json",
        responseSchema: input.schema,
      },
      systemInstruction: input.system,
    })

    const result = await model.generateContent(input.prompt)
    const response = result.response
    const rawText = response.text()
    const data = JSON.parse(rawText) as T

    return {
      data,
      rawText,
      model: "gemini-1.5-flash",
    }
  }
}
```

#### 3.3. (Альтернатива) Создание GroqAiProvider

Создать файл: `packages/parser/src/providers/groq.ts`

```typescript
import OpenAI from "openai"
import type { AiProvider } from "../types.js"

export class GroqAiProvider implements AiProvider {
  readonly name = "groq"
  private client: OpenAI

  constructor(apiKey: string) {
    this.client = new OpenAI({
      apiKey,
      baseURL: "https://api.groq.com/openai/v1",
    })
  }

  async runStructured<T>(input: {
    system: string
    prompt: string
    schema: object
  }): Promise<{ data: T; rawText: string; model: string }> {
    const response = await this.client.chat.completions.create({
      model: "llama-3.1-70b-versatile",
      messages: [
        { role: "system", content: input.system },
        { role: "user", content: input.prompt },
      ],
      response_format: { type: "json_object" },
      temperature: 0.1,
    })

    const rawText = response.choices[0].message.content ?? "{}"
    const data = JSON.parse(rawText) as T

    return {
      data,
      rawText,
      model: response.model,
    }
  }
}
```

#### 3.9. Обработка ошибок API

Добавить retry логику и обработку rate limits:

```typescript
async runStructured<T>(input: { system: string; prompt: string; schema: object }): Promise<...> {

    const result = await model.generateContent(input.prompt)
    // ...
  } catch (error: any) {
    // Обработка rate limit
    if (error.status === 429) {
      throw new Error("Rate limit exceeded. Please try again later.")
    }
    // Обработка других ошибок

      throw new Error("Invalid API key. Check GEMINI_API_KEY environment variable.")
    }
    throw error
  }
}
```
