# SpecRails

**SpecRails** — это фреймворк и набор утилит, которые создают структурированные и предсказуемые AI-спецификации из обычного текстового описания.

Проект предназначен для системных аналитиков, архитекторов и разработчиков, которые хотят использовать ИИ **как инструмент формализации**, а не диалоговую игрушку.

Цель SpecRails — сделать выход AI **повторяемым, контролируемым и инженерным**.

---

## Концепция

AI не должен быть «волшебным собеседником».
AI должен быть **утилитой в вашем рабочем процессе**.

- пользователь пишет текст
- вызывает утилиту (`/form`, `/model`, `/roles`, `/fsm`)
- получает структурированный результат
- принимает решение → сохраняет

Ключевая особенность SpecRails:
- **Система сама улучшает свои промпты** — автокоррекция на основе анализа ошибок
- AI улучшает AI через Meta-Prompt Engine
- A/B тестирование новых версий промптов
- Автоматическое применение при улучшении > 10%

Философия проекта:

- минимальная когнитивная нагрузка
- AI скрыт за «рельсами» (структурными ограничителями)
- детерминизм как направление развития
- человек контролирует финальный результат
- **система учится на своих ошибках автоматически**

## Принципы

- **KISS** — простые утилиты, маленькие функции
- **YAGNI** — ничего лишнего
- **AI как механизм, не персона**
- **контроль > магия**
- **структура > творческая случайность**
